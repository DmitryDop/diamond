`bita.png` — побайтовая копия `../diamond-bat.png`, 1672 × 941, без обрезки, поворота и перерисовки в самом файле. Поворот −15° и утверждённые размеры/позиции применяются при сборке. Файл содержит целиком рукоять и ударную часть, даже когда края объекта уходят за пределы кадра композиции.

## Сборка

Координаты отсчитываются от верхнего левого угла общего атмосферного холста 1672 × 941. Дымка и все бриллианты масштабируются одним коэффициентом; их смещения масштабируются тем же коэффициентом. Относительные размеры/позиции: `left = x / 1672`, `top = y / 941`, `width = width / 1672`, `height = height / 941`.

Непрозрачность каждого бриллианта — 0,8. Порядок наложения текущей композиции: фон `#0b0b0e` → дымка → бриллианты → бита → текст. Метки `front/mid/back` и `parallax_rank` определяют глубину для будущего независимого движения; текущий порядок наложения сохранён, чтобы не менять утверждённое перекрытие объектов.

Бита живёт в координатах всей арт-сцены, а не атмосферного холста:

- Desktop: ширина 98%, left −8%, top 0, поворот −15°, origin 55% 50%.
- Mobile: ширина 162%, left −30%, top 13%, тот же поворот и origin.
- Tablet 851–1100 px: ширина 108%, left −14%, top 6%.

Живая статическая сборка из этих PNG — `../../qa/diamond-texture-preview.html`. Каждый объект имеет свой `data-layer`, бриллианты — `data-depth`. Анимаций и обработчиков прокрутки нет.

## Цельные композиции

- `placeholder-1440.png` — 1440 × 900, вся арт-сцена без текста.
- `placeholder-1920.png` — 1920 × 1200, вся арт-сцена без текста.
- `placeholder-mobile-390.png` — 390 × 523, мобильная арт-сцена без текста.
- `atmosphere-composite.png` — 1672 × 941, контрольная сборка только дымки и бриллиантов на графитовом фоне.

Placeholder-файлы содержат фон и исходное кадрирование сцены. В них не запечена внутренняя маска затухания блока; её можно добавить позже в вёрстке. Отдельные объекты экспортированы до этой маски.

## Проверка и воспроизведение

Alpha-края бриллиантов проверены на графитовом и белом фоне: `../../qa/diamond-texture-cutouts-contact-sheet.png`. Полная бита проверяется совпадением SHA-256 с исходником. Координаты сверены с HTML и манифестом.

Подготовка PNG: `../../qa/prepare-texture-layers.swift`. Статические preview и placeholder: `../../qa/render-texture-preview.swift`. Рендеры AppKit показывают композицию; они не являются браузерными скриншотами.

Отдельная дымка подготовлена встроенным `image_gen` с двумя изображениями: текущая атмосфера как цель редактирования и «Характер» как цветовой референс. Бита и бриллианты не генерировались заново.
