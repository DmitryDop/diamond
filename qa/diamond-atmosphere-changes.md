# Проверка изменений атмосферы

Изменены index.html, css/styles.css, js/main.js. Созданы PNG и layers.json в assets/diamond-atmosphere/, скрипты и отчёты в qa/.

HTML вне визуала impact идентичен сохранённой перед задачей версии; существующие правила CSS отличаются только RGB градиентов; существующий JS отличается только синхронизацией прежней анимации с новым слоем. Все прежние ассеты сохраняют SHA-256. Локальные ссылки доступны, node --check прошёл.

Оттенок взят из существующей дымки «Характера». Прозрачность, остановки и геометрия CSS-градиентов сохранены; светимость подобрана к прежним значениям. Дымка impact увеличена на 12% относительно собственного центра; пиксели защищённых предметов сохранены. Парные слои «Характера» собираются без RGB-различий в исходном размере. В текущей вёрстке сохранены исходные JPEG «Характера», поскольку уменьшение JPEG и PNG может отличаться.

Браузерная визуальная проверка недоступна в этой среде. Контрольная сборка impact проверена как изображение; масштабирование в браузере не заявляется проверенным.
