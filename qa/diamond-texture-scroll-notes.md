# «Фактура»: спокойный параллакс

- Существующий placeholder собран из имеющихся bita.png, smoke.png и десяти diamond-*.png. Новые продуктовые ассеты не создавались и существующие PNG не редактировались.
- Размеры и размещение взяты из сборки существующих placeholder: desktop 8:5, mobile 390:523. Бита — ширина 98%, left -8%, top 0 на desktop; 162%, left -30%, top 13% на mobile; исходный поворот -15°, origin 55% 50%.
- Существующий picture сохраняет высоту сцены и служит резервом. Только после декодирования всех слоёв включается живая сборка. При ошибке загрузки или отсутствии GSAP остаётся placeholder.
- ScrollTrigger texture-scroll: trigger .texture-art, top 85% → top -25%, scrub:true, без pin и временного сглаживания. Одна timeline texture-parallax, ease:none.
- Поворот биты: -15° → -7° desktop, -15° → -11° mobile. Размеры и масштаб не анимируются.
- Крупные камни: движение по разным диагоналям на 38–48 px; мелкие камни размером 70–80 px: 62–65 px. Mobile — половина амплитуды.
- Дымка статична: тот же файл, opacity .28, координаты исходной сборки. Все существующие градиенты, маски и типографика сохранены.
- Обратный скролл полностью возвращает исходное положение; остановка прокрутки сохраняет текущий кадр. Reduced motion оставляет статическую композицию.

## Проверка

`node --check js/main.js` — успешно.
`swift qa/check-texture-full-page.swift` — полная страница в WebKit на 1440, 1920, 390, 320 px: остановка движения, амплитуды, обратный ход, неизменность размеров/координат layout, неподвижная дымка и прежняя маска, refresh, отсутствие overflow.

Начальная живая сборка сравнена со старым PNG на 1440 и 390 px. Средняя разница RGB по шкале 0–255: 1.71 desktop и 2.68 mobile. Из-за отдельного браузерного масштабирования и смешивания прозрачных слоёв результат не попиксельно идентичен рендеру AppKit, но кадрирование и композиция сохранены. Сравнение выявило и позволило исправить ограничение max-width:100% на мобильной бите.

В тесте меняется реальная позиция прокрутки; таймлайн не перемещается вручную для проверки движения. Только сравнение статической композиции использует timeline.progress(0). Физическое колесо и FPS не измерялись. Desktop/mobile превью просмотрены.

Файлы: index.html, css/styles.css, js/main.js.
QA: check-texture-full-page.swift, diamond-texture-full-page-scroll-validation.json, diamond-texture-full-page-assembly-validation.json. Полная страница включает соседние сцены и их ScrollTrigger; локальные URL при встраивании ресурсов декодируются. Значения bigDistances/smallDistances в JSON нормализованы на desktop; мобильные реальные смещения вдвое меньше.
Превью: ../previews/02-texture-full-page-{1440,1920,390,320}-normal.png.

## Корректировка после записи экрана

Просмотрены восемь кадров пользовательского screencast 2026-10-14 21-38-52.mp4 (10.783 секунды). Предыдущая амплитуда 4° / 20–27 px на длинном диапазоне скролла плохо читалась. По последующей просьбе сделать движение на своё усмотрение усилены только transform биты и алмазов, диапазон сокращён до 110% высоты viewport. Использованы рекомендации ui-ux-pro-max для GSAP scroll scrub. Ассеты, дымка, головы и другие сцены в этой корректировке не изменялись.
