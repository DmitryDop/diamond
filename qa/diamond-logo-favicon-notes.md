# Логотип DIAMOND и favicon

## Результат

Inline SVG в шапке оптимизирован SVGO 4.1.0: **13 893 → 9 742 байта, −29,9%**, включая добавленный `aria-hidden` внутри именованной ссылки. Standalone-версия после SVGO: 9 723 байта.

Сохранены `viewBox="0 0 203 48"`, белый цвет, исходные пропорции и ссылка `href="#top"` с `aria-label="DIAMOND — к началу"`. Убраны clipPath, defs и старые закомментированные версии. Общий белый fill вынесен на SVG. Контуры оставлены раздельными: их слияние меняло сглаживание на стыках.

Chrome: исходный и итоговый логотипы **попиксельно идентичны** при 203×48, 406×96 и 812×192. Отдельно проверено, что удаление clipPath не меняет ни одного пикселя.

## Favicon

- `favicon.svg`: белый бриллиант на чёрном фоне, viewBox 0 0 32 32; контур восстановлен по предоставленному растру `assets/32.png`, без элементов полной эмблемы.
- `favicon.ico`: три PNG-кадра 16×16, 32×32, 48×48. Кадр 32×32 содержит предоставленный файл **байт в байт**.
- `apple-touch-icon.png`: 180×180, тот же знак и чёрный фон.

Для размеров 16, 48 и 180 рассчитана точная площадь пересечения контура с каждым пикселем: чёткий сглаженный край без повторного увеличения маленькой картинки. Сглаживание SVG в Chrome отличается от исходного PNG на границах; исходная версия 32×32 сохранена в ICO.

Все три файла подключены в head по реальным корневым путям. На текущем сервере каждый возвращает HTTP 200 с правильным MIME. Chrome сам запросил favicon.svg и favicon.ico; ошибок консоли и HTTP нет.

## Мобильная шапка

Проверены 320×740, 390×844 и 1440×900. Логотип пропорционально сжимается при нехватке места; кнопки сохраняют свою ширину. Горизонтальное переполнение устранено. SVG сохраняет исходный viewBox, desktop-размер 203×48 не меняется.

Проверки выполнены отдельным установленным Chrome в headless-режиме. Скриншоты: `previews/final-header-1440.png`, `previews/final-header-390.png`, `previews/final-header-320.png`, `previews/logo-favicon-review-1440.png`. Живая вкладка подключённого браузера была недоступна, поэтому её интерфейс визуально не проверялся.
