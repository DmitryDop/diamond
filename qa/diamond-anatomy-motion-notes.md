# Анатомия — анимация

Реализовано по `DIAMOND_PROJECT_KIT/anatomy.md` на существующих GSAP 3.13.0 и ScrollTrigger.

- 0–12%: цельная бита; 12–32%: перекрывающаяся подмена; 25–76%: раскрытие; 71–83%: проявление выносок; 83–100%: пауза для рассмотрения.
- Индивидуальные начальные смещения заданы в пикселях исходного холста и пересчитаны в проценты. Масштаб всех слоёв одинаковый. Финальные смещения и повороты равны нулю.
- На desktop секция фиксируется под шапкой на 180% высоты viewport; на телефоне сценарий сокращён до 115%. На планшетах 521–1100 px и экранах высотой до 720 px используется обычная прокрутка без фиксации.
- `prefers-reduced-motion`: статичные исходные слои и выноски, без триггера Anatomy.
- «Рассмотреть детали» открывает статичную увеличенную композицию с горизонтальной прокруткой. Подписи остаются частью исходного PNG. Диалог поддерживает клавиатуру и Escape.
- Для стабильности при resize точка начала рассчитывается по позиции отдельного контейнера в документе. Непрозрачная подложка сохраняет существующий градиент и предотвращает просвечивание предыдущей секции при фиксации.

## Проверка

Chrome, настоящие HTML/CSS/JS проекта в iframe с заданными размерами: 320×740, 390×844, 850×980, 1100×800, 1101×900, 1440×900, 1920×1080 и 1440×600. Отдельно reduced motion при 390×844 и 1440×900. Все 144 проверки прошли.

Проверены прямой/обратный скролл, перекрытие фаз подмены, отсутствие движения без скролла, исходные координаты в финале, снятие фиксации, refresh, отсутствие горизонтального переполнения, открытие/закрытие увеличенной схемы. Переходы 1440 → 390 → 850 → 1440: ещё 48 проверок без ошибок и дублирования триггеров. Визуально проверены цельная бита, подмена, финальные выноски на desktop и mobile.

Исходные PNG не изменены: контроль SHA-256. HTML, CSS и JS вне блока Anatomy совпадают со снимком до начала задачи.

## Файлы

Изменены: `index.html`, `css/styles.css`, `js/main.js`.

Созданы:
- `qa/anatomy-motion-review.html` — интерактивная проверка и просмотр исходных слоёв.
- `qa/anatomy-motion-review-script.js` — сценарии браузерной проверки.
- `qa/diamond-anatomy-motion-validation.json` — итоговые результаты.
- `qa/diamond-anatomy-motion-scope-validation.json` — границы изменений.
- `qa/diamond-anatomy-motion-before.json` — исходный снимок трёх файлов.
- `qa/diamond-anatomy-motion-asset-hashes.json` — исходные хеши ассетов.
- `qa/diamond-anatomy-motion-notes.md` — этот отчёт.

Открыть проверку через локальный сервер: `/qa/anatomy-motion-review.html`. Кнопки «Все размеры» и «Проверить resize» запускают проверки повторно. Тестовые страницы не подключены к основному сайту.
