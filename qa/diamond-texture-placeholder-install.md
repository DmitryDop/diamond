# Фактура — установка placeholder

Установлена цельная композиция в настоящий `index.html`, секция `#texture`.

## Изменённые файлы

- `index.html` — вместо старого макро-ассета подключён `<picture>` с тремя подготовленными изображениями. Подпись под визуалом убрана согласно предыдущей правке Дмитрия. Заголовок, номер и описание сохранены дословно в HTML. Добавлен якорь `#texture` для просмотра.
- `css/styles.css` — стили только для «Фактуры»: цельная сцена занимает всю ширину секции, текст сохраняет правую колонку desktop и положение над сценой mobile. Маска перенесена из утверждённого preview и действует только внутри figure, ниже HTML-текста. Фон секции сохранён.

Созданные материалы проверки:

- `qa/check-texture-webkit.swift` — попытка браузерного рендера настоящих HTML/CSS/ассетов через WebKit, включая автономную копию для исключения сетевых запросов.
- `qa/diamond-texture-webkit.log` — ошибки браузерного запуска.
- `qa/diamond-texture-placeholder-validation.json` — статические проверки и статус браузерной проверки.
- `qa/diamond-texture-placeholder-install.md` — эта запись.

## Выбор изображения

| Ширина окна | Файл | Размер источника | Масштабирование |
|---|---|---|---|
| ≤850 px | placeholder-mobile-390.png | 390 × 523 | width:100%; height:auto |
| 851–1599 px | placeholder-1440.png | 1440 × 900 | width:100%; height:auto |
| ≥1600 px | placeholder-1920.png | 1920 × 1200 | width:100%; height:auto |

Desktop-источники имеют одинаковое отношение сторон 8:5. Высота визуальной области desktop равна 62,5vw. Mobile использует собственное отношение сторон 390:523. Изображение не растягивается по двум осям, не обрезается `object-fit:cover` и не поворачивается повторно. Кадрирование предметов взято из готовых PNG.

В секции нет дополнительных изображений дымки или бриллиантов, светового halo и новых анимаций. `js/main.js` не изменён. Отдельные PNG, placeholder, README набора и `layers.json` сохранены побайтово.

## Проверка

Пройдены статические проверки: локальные пути, уникальные HTML ID, дословное сохранение текстового блока, неизменность HTML остальных секций, неизменность CSS-правил остальных секций и SHA-256 всех файлов подготовленного набора. Выбор источников и пропорции проверены для 390, 768, 1024, 1440, 1536 и 1920 px по HTML/CSS и размерам PNG.

**Браузерная проверка не выполнена; браузерные скриншоты не получены.** Подключённые IAB и Chrome недоступны. Установленный локальный Chrome в headless-режиме завершился с кодом 134. WebKit с временным хранилищем и автономными ресурсами не завершил загрузку/снимок; журнал содержит ошибки OpenCL/IOSurface, попытки завершаются по тайм-ауту. Существующие AppKit preview не выдаются за скриншоты новой реальной вёрстки.

Остаётся проверить реальный `index.html#texture` в работающем браузере на 390, 1440, 1920 px и промежуточных ширинах, снять скриншоты и подтвердить читаемость/кадрирование. До отдельной команды работа над параллаксом и общей системой анимаций не начинается.
