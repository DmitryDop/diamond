# Независимые слои атмосферы

Все PNG получены локальной обработкой существующих JPEG без генерации изображений. Размеры и координаты указаны в layers.json. Параллакс не реализован.

- impact-base.png + impact-smoke.png — подготовленная композиция с холодной дымкой, увеличенной на 12%. Защищённые пиксели предметов сохранены.
- impact-adjustment.png — используемая сейчас фоновая коррекция поверх исходного diamond-impact.jpg, чтобы сохранить оригинальное уменьшение JPEG и существующие предметы.
- character-base.png + character-smoke.png и мобильная пара — отдельные слои; в исходном размере собираются в исходную сцену без изменения RGB.
- «Характер» сейчас использует исходные JPEG: это сохраняет текущий вид при уменьшении изображения. Подключение отдельных PNG отложено до следующего этапа.
- *-composite-check.png — контрольные сборки, в лендинге не используются.

Не добавлять smoke поверх исходного JPEG: это удвоит дымку. При будущем подключении использовать base + smoke вместе.
