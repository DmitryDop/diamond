Переделай анимацию блока «Когда аргумент очевиден». Текущая реализация не соответствует задаче.

### Главное изменение

Нужна анимация, напрямую управляемая скроллом, а не автоматически проигрываемый ролик.

Используй GSAP ScrollTrigger с `scrub: true`.

**Поведение:**
- Скролл вниз — бита постепенно приближается к голове.
- Скролл остановился — бита немедленно останавливается в текущем положении.
- Продолжаем скролл — бита движется дальше.
- В точке контакта целая голова мгновенно заменяется разбитой.
- Скролл вверх — вся последовательность воспроизводится в обратном направлении: бита отъезжает, голова снова становится целой.
- Никаких самостоятельных анимаций удара, `play()`, таймеров и `scrub: 1`.

### Распределение скролла

- 0–75% — длинное постепенное приближение биты по диагонали к голове.
- 75–80% — контакт, подмена головы, лёгкий импульс.
- 80–100% — небольшое движение биты по инерции и финальное состояние.

Основная драматургия — именно в длительном приближении биты.

### Положение блока

Анимация не должна начинаться, пока пользователь практически не увидел композицию.

Проверь существующий ScrollTrigger. Если для полноценной демонстрации движения не хватает расстояния прокрутки, используй короткий `pin` с дополнительным scroll-distance приблизительно 80–100vh.

Фиксация должна начинаться только тогда, когда основная композиция уже находится во viewport.

Не устраивай длинную pinned-секцию на несколько экранов.

Дымка может слегка реагировать на скролл, но не должна автоматически проигрывать самостоятельную анимацию.

### Технически

- Одна GSAP timeline с ScrollTrigger.
- `scrub: true`, без временного сглаживания.
- `ease: "none"` для линейного соответствия прокрутке; характер движения биты можно задать ключевыми точками самой timeline.
- Обратное движение должно восстанавливать исходное состояние без скачков.
- Подмена голов — дискретная, без crossfade разных лиц.
- Корректная работа при быстром скролле и изменении размера окна.

**Критерий готовности:** я могу колесом мыши медленно подвести биту к голове, остановить за сантиметр до удара, прокрутить дальше и разбить голову. Затем прокрутить назад и полностью восстановить исходную сцену.
