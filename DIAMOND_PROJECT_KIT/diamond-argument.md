- Лицо не менять.

- Биту не менять.

Что нужно сделать по слоям
Подготовь сцену в виде отдельных прозрачных слоёв для дальнейшего параллакса:
1. Бита — отдельный прозрачный слой.
   - На бите не должно быть осколков, пыли или фрагментов головы.
   - Допустимы только:
     - лёгкий рефлекс от головы,
     - естественная тень / затемнение,
     - собственные блики биты.
2. Голова — отдельный прозрачный слой.
   - С пробоиной, трещинами и осколками.
   - Без биты.
3. Дымка / пыль — отдельный прозрачный слой.
   - Мягкая,
   - цельная,
   - без вырезов и дыр,
   - пригодная для отдельного параллакс-слоя.
Важно
- Все слои должны быть подготовлены так, чтобы их можно было сложить обратно в ту же сцену почти без смещения.
- Итог должен выглядеть как чистый dark luxury placeholder для лендинга.
- Никаких новых объектов не добавлять.
- Цвета, платину, тональность и общий стиль сцены сохранить.
