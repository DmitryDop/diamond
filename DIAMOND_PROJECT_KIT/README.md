# DIAMOND / Starter

**Начать с:**

1. Распаковать этот комплект в **отдельную** папку проекта DIAMOND.
2. Открыть эту папку в Codex.
3. Передать Codex задачу: **«Выполни `CODEX_TASK_01.md` строго по `DIAMOND_MASTER_BRIEF.md`. Начни только с каркаса; не делай deploy, push или commit».**
4. Открыть готовый `index.html` через локальный сервер, посмотреть desktop и mobile.
5. Вернуться с замечаниями; затем перейти к GSAP (итерация 2).

**Файлы:**

- `DIAMOND_MASTER_BRIEF.md` — все решения и критерии качества.
- `CODEX_TASK_01.md` — конкретное задание Codex на первый проход.
- `CODEX_TASK_02_GSAP.md` — задание на второй проход, **только после утверждения каркаса**.
- `../assets/diamond-bat.png` — платиновая бита на **прозрачном фоне**.
- `../assets/diamond-glyph.svg` — редактируемая базовая геометрия бриллианта-«O» (подгонять оптически).
- `refs/` — эталонные скриншоты (не UI-активы).
- `legacy/` — старый HTML-прототип и примерка шрифтов (исходники для ориентирования, не final).

**На первом этапе:** не менять PALKAHELP; все коммерческие переходы → `https://palkahelp.ru`; на Diamond нет формы заказа.

## Итерация 1 — рабочий каркас

Рабочие файлы находятся в корне `daimond`: `index.html`, `css/styles.css`, `js/main.js` и `assets/`. Инструкции, `refs/` и `legacy/` оставлены в `DIAMOND_PROJECT_KIT`. Пути внутри HTML сохранены: ассеты, стили и JS расположены относительно него так же, как до переноса. Установка пакетов не нужна.

Запуск из папки проекта `daimond`:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть **http://127.0.0.1:8000/**. Остановить сервер: `Ctrl+C` в терминале запуска. Можно открыть `index.html` напрямую; для Google Fonts нужен интернет. Без сети используются системные шрифты.

Собраны hero, концепция, три последовательные сцены деталей, финальный переход и footer. Внешние CTA ведут на главную PALKAHELP; локальных форм заказа нет. Навигация, мобильное меню и содержимое работают без JS. В сцене «Фактура» увеличен фрагмент исходного PNG — отдельного макроснимка нет. Текст концепции остаётся рабочим по брифу.

GSAP, движение объекта, параллакс и появление заголовков по буквам отложены до утверждения каркаса и итерации 2.

### Проверки первой итерации

Статические проверки пройдены: корректная вложенность HTML и SVG, уникальные ID, 11 внутренних ссылок на существующие якоря, 4 внешние ссылки строго на `https://palkahelp.ru`, наличие локальных ассетов, синтаксис JS. Форм, диалогов, табов, декоративных стрелок и GSAP в рабочей странице нет. Контраст цветовых токенов текста к фону секции: основной текст 9.33:1, подписи 7.21:1; текст основного CTA 16.13:1. Это расчёт токенов, не измерение отрисованного изображения.

Браузерная проверка **не выполнена**: в среде исполнения нет подключённого браузера, а запуск локального HTTP-сервера запрещён ограничениями среды (`PermissionError` при открытии порта). Сервер сейчас не запущен. Команда выше предназначена для запуска в вашем терминале.

Для визуального просмотра остаются 1920×1080, 1440×900, 768 px, 390×844 и 375×812: проверить отсутствие overflow, геометрию заголовка и биты, клики/якоря, консоль, фактическую загрузку Manrope + Inter, режим без JS и reduced motion.

Использован `ui-ux-pro-max` для рекомендаций по адаптивности и доступности; визуальные решения взяты из утверждённого брифа. `frontend-design` в окружении не найден; работа продолжена согласно разрешению в `CODEX_TASK_01.md`.
